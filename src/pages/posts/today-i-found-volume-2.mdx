## Online Services

- [Visual Subnet Calculator](https://visualsubnetcalc.com/): A network design utility that allows you to split and join subnets using a simple GUI. The results can be customized and shared with collaborators. 

- [13 Feet Ladder](https://github.com/wasi-master/13ft/): Described as a `self hosted paywall destroyer`, 13ft is a self-hosted service that allows you to bypass paywalls and extends the functionality of its inspiration http://12ft.io. 

Inspired by a recent [post](https://alexwlchan.net/2024/static-websites/) I got the itch to dive back into HTML and build some small static sites for my local home network.  To get a sense of how the layout would look displaying various media types I needed some placeholder graphics of varying sizes and stumbled upon the following resources:

- [Placehold](https://placehold.co/): A simple, fast and free image placeholder service that allows you to customize image size, color, text, font, etc

- [LoremFlickr](https://loremflickr.com/): Provides placeholder images using photos from Flickr that have a Creative Commons license. It has a great free option or a low cost pro tier that gets you a bit more customization. 

## Terminal

- [10 Examples Why cURL is an Awesome CLI Tool](https://martinheinz.dev/blog/113): While I do use cURL a fair amount, I have to admit I only knew about 3 of the uses mentioned in this post. If you like posts on python and cli fun, give Martins blog a follow.  

- [viking](https://github.com/d3witt/viking): A handy tool for managing remote machines using SSH. When the utility I had used previously was deprecated, I looked around for another tool to help manage remote ssh sessions and found Viking. Beyond managing the ssh sessions and connection details, Viking also allows you to run remote commands and copy files to and from remote machines. 

- [tiptop](https://github.com/nschloe/tiptop?ref=terminaltrove): A python based TUI monitoring tool in the spirit of `top`. Found via the excellent [terminaltrove](https://terminaltrove.com/).
