Just 2 little tools I have run across recently that I wanted to highlight:

- [television](https://crates.io/crates/television): an amazing cross-platform, fuzzy finder TUI that lets you quickly search through any kind of data source (files, git repositories, environment variables, docker images, etc). For a long time I was a huge fan of `ag` as a `find` replacement but `television` has really taken over as my default terminal search utility. 

- [httptap](https://github.com/monasticacademy/httptap): Found via the great [TLDR newsletter](https://tldr.tech/webdev), this handy utility allows you to view HTTP/HTTPS requests made by any Linux program. I recently used this to see what call and responses were being used for some `ibmcloud` cli commands that were not returning the expected output.
